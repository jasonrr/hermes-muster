# Plans (historical record)

Each file here is the design or implementation plan for one past piece of work, dated when it was written and kept
as it was approved. Later work may have changed or replaced what a plan describes, so a plan is not a description of
current behavior and not a set of operating instructions. For how muster works today, read the
[README](../../README.md).

Builders add new plans here as part of their work (see `prompts/builder-workflow.md`).
