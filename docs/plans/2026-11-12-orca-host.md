# Plan: Orca as an optional terminal host

**Goal:** muster runs every route (issue runs, ad-hoc runs, `hermes muster open` analysis workspaces, holds,
decisions, cleanup) on either herdr (default, unchanged) or Orca, picked by a global `host` setting. Each record
remembers the host it was made on.

## Deliberate departures from the design

These were decided while planning, from the live check below:
- **`--setup skip`, not `inherit`:** builders own dependency setup (#69), and a repo's synchronous setup hook once
  stalled a launch for 308 s (learnings L191).
- **Listing comes from `git worktree list --porcelain`, not `orca worktree list`:** Orca's list leaves out
  checkouts it did not create.
- **A git checkout for an existing branch:** Orca renames such a branch.
- **The pane key carries Orca's original pane id, not only the title:** after an Orca restart, terminals come back
  "orphaned" with no title.

## Live check (done 2026-11-12, during planning, on this machine's Orca)

The real `orca` CLI was driven against a throwaway repo. The fakes and code below encode these facts. Do not
re-spike them. Task 10 re-checks them against real Orca.

| Question | What Orca does |
|---|---|
| Binary | `/Applications/Orca.app/Contents/Resources/bin/orca`. It is **not** on cron's bare PATH, and neither is `lsof`, which is `/usr/sbin/lsof`. |
| Errors | `orca … --json` exits 1 and prints `{"ok": false, "error": {"code": "<code>", …}}` on **stdout**. stderr is empty. Codes seen: `repo_not_found`, `selector_not_found`, `terminal_handle_stale`, `agent_prompt_blocked`. |
| Repo id | `orca repo show --repo path:<clone> --json` returns `result.repo.id`, or fails with `repo_not_found`. `orca repo add --path <p> [--kind folder] --json` returns `result.repo.id`. There is no `repo rm` in the CLI. |
| New worktree | `orca worktree create --repo id:<rid> --name <n> --branch <b> --base-branch origin/<base> --setup skip --no-parent --json` returns `result.worktree.{id, path, branch}`. id is `<rid>::<path>`, path is `~/orca/workspaces/<clone dir name>/<n>`, and branch is `refs/heads/<b>`. It also opens one plain, untitled shell terminal in that worktree. |
| Existing branch | A branch with commits of its own is silently **renamed** (`muster/3` became `muster/3-2`). So muster uses `git -C <clone> worktree add <path> <branch>` instead, then `orca repo set --repo id:<rid> --external-worktree-visibility show`. Orca opens terminals in such a checkout, but `orca worktree list` leaves it out. |
| Remove | `orca worktree rm --worktree path:<p> [--force] --json` removes Orca-created and git-created checkouts alike, closes their terminals and keeps the branch. |
| Terminal | `orca terminal create --worktree <sel> --title <t> --json` returns `result.terminal.{handle, processId, worktreeId, paneKey, tabId, ptyId}`, with `paneKey` = `<tabId>:<leafId>`. `--title` becomes the pane's `paneTitle`, which `orca terminal list` shows within about a second. Once, an immediate `set-pane-title` got `terminal_handle_stale`. `processId` is a `/usr/bin/login` wrapper and the shell (`-/bin/zsh -l`) is its child. A `--worktree path:` naming a subdirectory and not a workspace fails with `selector_not_found`. |
| Terminal list | `orca terminal list [--worktree id:<wt>] --json` returns `result.terminals[]` with `handle, worktreeId, worktreePath, tabId, leafId, ptyId, paneTitle, orphaned, connected, agentIdentity`. **Orphaned rows** exist: terminals whose PTY lives (`connected: true`) but which no window shows, as after an Orca restart. Such a row has `orphaned: true`, `paneTitle: null`, synthetic `tabId`/`leafId` (`pty:…`), and `recordedPaneKey` = the original `<tabId>:<leafId>`. `worktree ps` shows **no agent** for an orphaned terminal. Six such rows were seen on this machine. |
| Claude in Orca | Orca wraps `claude` in its shells (it adds `--plugin-dir …/orca-agent-view`). Its agent detection depends on that wrapper, so muster types `claude …` into the shell and never runs `env … claude`. The process argv[0] is `claude`. |
| Agent state | `orca worktree ps [--limit <n>] --json` returns `result.worktrees[].{worktreeId, path, agents[]}`, where each agent has `{paneKey, state, agentType, agentWait, stateStartedAt, …}`. A fresh idle Claude reads `done`. Mid-turn reads `working`. A trust dialog or an AskUserQuestion reads `waiting` (`agentWait.reason: agent-trust-workspace`, or `agentWait.source: hook`). An exited Claude leaves `agents: []`. |
| Trust | A worktree of a repo Claude already trusts starts with no dialog. An untrusted one waits on the trust dialog (`waiting`). |
| Prompt | `orca terminal send --terminal <h> --text <t> --enter --wait-submit 30 --json` returns `result.send.prompt.stages`, which includes `"turn_started"` once the turn is proven. While the agent shows a dialog, it fails with `agent_prompt_blocked` and sends nothing. Plain `--text … --enter` with no `--wait-submit` into a shell returns `result.send.accepted: true`. |
| Screen | `orca terminal read --terminal <h> --screen --json` returns `result.terminal.tail` (a list of lines). |
| Processes | `lsof -a -d cwd -Fpn` exits 0 and lists `p<pid>` / `n<cwd>` lines. A terminal's shell has the worktree as its cwd, and so does the Claude in it. The login wrapper is unreadable and absent. |
| Folder workspace | `orca repo add --path <dir> --kind folder`, then `orca terminal create --worktree path:<dir>`. The terminal's `worktreeId` is `<folder repo id>::<dir>`. |

**Not checked: whether a window re-adopts orphaned terminals with their old `tabId:leafId`.** The planning session
runs inside Orca and could not restart it. The code below is safe either way: an orphaned terminal is "unknown,
try later", never "gone". Task 10 hands the check to the human.

2. Create `muster/hosts/__init__.py`:

```python
"""hosts: the terminal host a run lives in, one module per host, picked by name (`host` setting).

herdr is the default; orca is the option (docs/decisions/2026-11-12-orca-host.md). A host module is a peer of the
others; the contract is this docstring, no base class (the muster/channels pattern). Every host speaks herdr's dict
shapes and fills only the fields it really has. A record made before this seam names no host: it is herdr's.

- `NAME`: the module's name, as records store it.
- `worktree_path(clone, branch) -> str`: where a new checkout of branch goes.
- `worktrees(clone) -> [{"path", "branch", "open_workspace_id", "is_linked_worktree"}]`: every git worktree of
  the clone; branch is short (no refs/heads/); open_workspace_id is None when the host has none open.
- `create_worktree(clone, branch, base, path, label) -> {"workspace", "path"}`: a checkout of branch from
  origin/<base>; path is where it really is (the caller records it).
- `open_worktree(clone, path, label) -> workspace`: the host's workspace for an existing checkout.
- `panes(workspace) -> [{"pane_id", "workspace_id", "terminal_id", "agent"}]`: agent is the kind, or None.
- `pane(pane) -> {"pane_id", "workspace_id"} | None`: None only when the pane is gone.
- `open_tab(workspace, path, label, env, title) -> pane`: a shell tab in the checkout; title names the agent.
- `agent(target) -> {"agent", "name", "cwd", "foreground_cwd", "agent_status", "state_change_seq",
  "completion_seq", "pane_id", "workspace_id"} | None`: target is a pane or an agent name. None only when there is
  none; raises core.CommandError when the host cannot tell (try again later). agent_status is idle, working,
  blocked or done; anything else is neither ready nor delivered.
- `start_agent(name, kind, pane, args, env)`: start kind in the pane with args, returning once it is ready or shows
  a dialog; raises core.CommandError otherwise (the caller then reads `agent(pane)` itself).
- `prompt(pane, text) -> agent_status`: send one prompt; raises Blocked when refused before anything was sent,
  core.CommandError when delivery is unproven.
- `screen(pane) -> str`: what the pane shows now.
- `quiet(workspace) -> list`: each pane's evidence, JSON-serialisable; raises NotReady when one is busy or unknown.
- `remove_argv(workspace, path, force) -> argv`: the command that removes the checkout and its workspace.
- `open_workspace(cwd, label) -> {"workspace", "terminal", "pane"}`: an analysis workspace.
- `analysis_gone(rec) -> bool`: an analysis record's workspace was closed by hand.
- `analysis_check(rec)`: raises NotReady unless the record still names what is there.
- `close_argv(rec) -> argv`: closes an analysis workspace; raises NotReady when it cannot be named now.
"""

import importlib
import re

from .. import config, core
from ..config import ConfigError

NAMES = ("herdr", "orca")
READY = ("idle", "done")
DELIVERED = ("working", "blocked", "done")
# The only foreground processes a pane without an agent may run.
# The herdr layout's own tools: herdr-reviewr and herdr-file-view only show files; lazygit keeps
# nothing but the repository, and a change it has not committed still fails `clean`.
QUIET = {"zsh", "bash", "sh", "fish", "herdr-reviewr", "herdr-file-view", "lazygit"}
# Long-lived helpers an agent keeps under it while idle: MCP servers and language servers, named by
# the program or its first argument (`tally mcp`, `pyright-langserver`, `node .../langserver.index.js`),
# never by a path or word further along. An MCP server named otherwise keeps the workspace (safe side).
HELPER = re.compile(r"mcp|.+-mcp|mcp-.+|.*langserver.*|.+-language-server|.+-lsp", re.I)


class NotReady(Exception):
    """A check failed; the message says which."""


class Blocked(core.CommandError):
    """The host refused a prompt before sending anything: the agent shows a dialog."""


def get(name):
    if name not in NAMES:
        raise ConfigError(f"muster: host {name!r} is not one of {', '.join(NAMES)}")
    return importlib.import_module(f"{__name__}.{name}")


def of(record):
    """The host a record names: its own "host", else its launch's; neither (made before this seam) is herdr."""
    record = record or {}
    launch = record.get("launch") if isinstance(record.get("launch"), dict) else {}
    return get(record.get("host") or launch.get("host") or "herdr")


def configured():
    return get(config.settings["host"])


def processes():
    """pid -> (parent pid, command) of every process on this machine."""
    table = {}
    for line in core.run(["ps", "-A", "-o", "pid=,ppid=,command="]).splitlines():
        pid, ppid, *command = line.split(None, 2)
        table[int(pid)] = (int(ppid), command[0] if command else "")
    return table


def helper(command):
    """True when the program or its first argument is an MCP or language server."""
    return any(HELPER.fullmatch(word.rsplit("/", 1)[-1]) for word in command.split()[:2])


def under(shell, table):
    """(pid, depth below the shell, command) of every process the pane's shell started, however deep."""
    found = []
    for pid, (_, command) in table.items():
        up, depth = pid, 0
        while up in table and up != shell and up > 1 and depth < 64:
            up, depth = table[up][0], depth + 1
        if up == shell and pid != shell:
            found.append((pid, depth, command))
    return sorted(found)


def program(command):
    """A command line's program name: `-/bin/zsh -l` -> zsh, `/usr/local/bin/claude --model x` -> claude."""
    return (command.split() or [""])[0].lstrip("-").rsplit("/", 1)[-1]
```

2. Create `muster/hosts/herdr.py`. The code is today's code, moved:

```python
"""herdr: muster's runs in herdr (>= 0.9.3): a trusted worktree, a tab, Claude started empty, then the brief.

The two-phase protocol and every argv here are herdr's (agent-automation.mdx); muster.launcher's header explains
why. Moved from launcher.py and cleanup.py unchanged when the host seam came in.
"""

import hashlib
import json
from pathlib import Path

from .. import config, core
from . import READY, Blocked, NotReady, QUIET, helper, processes, under

NAME = "herdr"


def result(*args):
    return json.loads(core.run(["herdr", *args]))["result"]


def worktree_path(clone, branch):
    """herdr's own worktree layout (<worktrees.directory>/<repo>/<branch-slug>); passed as --path so a launch
    knows its checkout before it exists."""
    return str(core.worktrees_dir() / Path(clone).name / branch.replace("/", "-"))


def worktrees(clone):
    return result("worktree", "list", "--cwd", str(clone))["worktrees"]


def create_worktree(clone, branch, base, path, label):
    made = result("worktree", "create", "--cwd", clone, "--branch", branch, "--base", f"origin/{base}",
                  "--path", path, "--label", label, "--no-focus", "--trust-repository")
    return {"workspace": made["workspace"]["workspace_id"], "path": made["worktree"]["path"]}


def open_worktree(clone, path, label):
    return result("worktree", "open", "--cwd", clone, "--path", path, "--label", label, "--no-focus",
                  "--trust-repository")["workspace"]["workspace_id"]


def panes(workspace):
    return result("pane", "list", "--workspace", workspace)["panes"]


def pane(pane_id):
    try:
        return result("pane", "get", pane_id)["pane"]
    except core.CommandError as error:
        if "pane_not_found" in str(error):
            return None
        raise


def open_tab(workspace, path, label, env, title):
    """A fresh shell tab, not the layout's own claude pane: its start races any scripted exit. title: unused
    (herdr names the agent at start)."""
    argv = ["herdr", "tab", "create", "--workspace", workspace, "--cwd", path, "--label", label]
    for pair in env:
        argv += ["--env", pair]
    return json.loads(core.run([*argv, "--no-focus"]))["result"]["root_pane"]["pane_id"]


def agent(target):
    """herdr's agent for a pane or name, or None when herdr says there is none. Raises when herdr fails."""
    try:
        return result("agent", "get", target)["agent"]
    except core.CommandError as error:
        if "agent_not_found" in str(error) or "pane_not_found" in str(error):
            return None
        raise


def start_agent(name, kind, pane_id, args, env):
    """env: unused (the tab already carries it). herdr returns once Claude is idle-ready."""
    core.run(["herdr", "agent", "start", name, "--kind", kind, "--pane", pane_id, "--timeout", "120000", "--", *args])


def prompt(pane_id, text):
    try:
        got = result("agent", "prompt", pane_id, text, "--wait", "--until", "working", "--until", "blocked",
                     "--timeout", "30000")
    except core.CommandError as error:
        if "agent_blocked" in str(error):  # refused before any input was sent (agent-automation.mdx)
            raise Blocked(str(error)) from None
        raise
    return (got.get("agent") or {}).get("agent_status")


def screen(pane_id):
    return core.run(["herdr", "pane", "read", pane_id, "--source", "visible"])


def quiet(workspace):
    """Each pane's evidence. NotReady when a pane is busy."""
    listed = panes(workspace)
    if not listed or any(p.get("workspace_id") != workspace for p in listed):
        raise NotReady(f"workspace {workspace} lists no panes, or another workspace's")
    table = processes()
    seen = []
    for entry in sorted(listed, key=lambda p: p["pane_id"]):
        pid = entry["pane_id"]
        info = result("pane", "process-info", "--pane", pid)["process_info"]
        procs = info["foreground_processes"]
        # A job started with & or an agent's background command: anything under the shell that is
        # neither the pane's foreground program nor a helper. A job detached with nohup or setsid
        # leaves this tree, and closing the pane does not stop it either.
        if info.get("shell_pid") not in table:
            raise NotReady(f"pane {pid}: its shell {info.get('shell_pid')} is not running")
        tree = under(info["shell_pid"], table)
        foreground = {p.get("pid") for p in procs}
        busy = [c for p, depth, c in tree if not (depth == 1 and p in foreground) and not helper(c)]
```

```python
import json
from pathlib import Path

import muster.core as core
import muster.hosts.orca as orca
from tests.fake_herdr import World


def fail(argv, code):
    """Orca exits 1 with its JSON error on stdout; core.run keeps it (Task 1)."""
    raise core.CommandError(f"{' '.join(argv[:3])}: exit 1\n" + json.dumps({"ok": False, "error": {"code": code}}))


def ok(result):
    return json.dumps({"ok": True, "result": result})


class OrcaWorld(World):
    def __init__(self, tmp_path):
        super().__init__(tmp_path)
        self.repos = {}         # clone or folder path -> repo id
        self.visible = set()    # repo ids that show external worktrees
        self.terminals = {}     # handle -> {worktreeId, worktreePath, paneTitle, tabId, leafId, ptyId, shell, login,
                                #            late, orphaned, recordedPaneKey}
        self.orca_agents = {}   # handle -> {agentType, state, stateStartedAt}
        self.cwds = {}          # pid -> cwd (lsof)
        self.procs = {}         # pid -> (ppid, command) (ps)
        self.typed = []         # command lines typed into a shell
        self.title_late = 0     # terminal list calls before a new terminal shows its paneTitle
        self.agent_start = "done"   # what a typed `claude` shows first: done | waiting | working | none
        self.boot = []          # states a started agent passes through, one per `worktree ps`, before agent_start
        self.send_mode = "turn_started"  # turn_started | accepted (no turn proof) | blocked | lost (no hook)
        self.after_turn = "working"     # the agent state right after a proven turn start
        self.pid = 1000

    def wid(self, path):
        return f"{self.repos[self.worktrees[path]['clone']]}::{path}"

    def orca_live(self, clone, branch, title, state="done"):
        """A checkout with a titled terminal running Claude, made before this test. Returns (path, handle)."""
        self.repos.setdefault(str(clone), self.next_id("repo"))
        path, _ = self.worktree(clone, branch, orca.worktree_path(clone, branch))
        handle = self.terminal(self.wid(path), path, title)
        self.claude(handle, state)
        return path, handle

    def terminal(self, wid, path, title):
        handle = self.next_id("term_")
        self.pid += 2
        login, shell = self.pid, self.pid + 1
        self.procs[login] = (1, "/usr/bin/login -flpq u /bin/zsh -l")
        self.procs[shell] = (login, "-/bin/zsh -l")
        self.cwds[shell] = path
        self.terminals[handle] = {"worktreeId": wid, "worktreePath": path, "paneTitle": title,
                                  "tabId": self.next_id("tab"), "leafId": self.next_id("leaf"),
                                  "ptyId": f"{wid}@@{handle}", "shell": shell, "login": login,
                                  "late": self.title_late, "orphaned": False, "recordedPaneKey": None}
        return handle

    def pane_key(self, handle):
        t = self.terminals[handle]
        return f"{t['tabId']}:{t['leafId']}"

    def claude(self, handle, state):
        t = self.terminals[handle]
        self.seq += 1
        self.orca_agents[handle] = {"agentType": "claude", "state": state, "stateStartedAt": self.seq}
        self.pid += 1
        self.procs[self.pid] = (t["shell"], "claude --model opus")
        self.cwds[self.pid] = t["worktreePath"]
        t["agent_pid"] = self.pid

    def restart(self):
        """Orca restarted and no window shows the terminals yet: new handles, rows orphaned, titles and agents gone
        from Orca's view; the processes run on (live check)."""
        moved, agents = {}, {}
        for handle, t in self.terminals.items():
            new = self.next_id("term_")
            moved[new] = {**t, "orphaned": True, "recordedPaneKey": f"{t['tabId']}:{t['leafId']}",
                          "tabId": f"pty:{t['ptyId']}", "leafId": f"pty:{t['ptyId']}", "paneTitle": None,
                          "saved": t}
            if handle in self.orca_agents:
                agents[new] = self.orca_agents[handle]
        self.terminals, self.hidden_agents, self.orca_agents = moved, agents, {}

    def adopt(self):
        """A window shows the terminals again, with their old tab and leaf (assumed; Task 10 checks) but no title."""
        for handle, t in list(self.terminals.items()):
            if t.get("orphaned"):
                self.terminals[handle] = {**t["saved"], "paneTitle": None, "late": 0}
        self.orca_agents.update(getattr(self, "hidden_agents", {}))
        self.hidden_agents = {}

    def dispatch(self, argv):
        if argv[0] == "orca":
            assert argv[-1] == "--json", argv
            return self.orca(argv)
        if argv == ["lsof", "-a", "-d", "cwd", "-Fpn"]:
            return "".join(f"p{pid}\nn{cwd}\n" for pid, cwd in self.cwds.items())
        if argv == ["ps", "-A", "-o", "pid=,ppid=,command="]:
            return "".join(f"{pid} {ppid} {cmd}\n" for pid, (ppid, cmd) in self.procs.items())
        return super().dispatch(argv)

    def git(self, where, args):
        if args == ["worktree", "list", "--porcelain"]:
            out = f"worktree {where}\nHEAD sha\nbranch refs/heads/main\n\n"
            for p, w in self.worktrees.items():
                if w["clone"] == where:
                    out += f"worktree {p}\nHEAD sha\nbranch refs/heads/{w['branch']}\n\n"
            return out
        if args[:2] == ["worktree", "add"]:
            path, branch = args[2], args[3]
            assert (where, branch) in self.branches, "git worktree add of a branch that does not exist"
            assert not any(w["branch"] == branch and w["clone"] == where for w in self.worktrees.values())
            self.worktree(where, branch, path)
            return ""
        return super().git(where, args)

    def advance_boot(self):
        for state in self.orca_agents.values():
            if state.get("boot"):
                state["state"] = state["boot"].pop(0)

    def orca(self, argv):
        args = argv[1:-1]

        def opt(flag):
            return args[args.index(flag) + 1]
        verb = args[:2]
        if verb == ["repo", "show"]:
            path = opt("--repo").removeprefix("path:")
            if path not in self.repos:
                fail(argv, "repo_not_found")
            return ok({"repo": {"id": self.repos[path], "path": path}})
        if verb == ["repo", "add"]:
            path = opt("--path")
            self.repos.setdefault(path, self.next_id("repo"))
            return ok({"repo": {"id": self.repos[path], "path": path}})
        if verb == ["repo", "set"]:

            self.visible.add(opt("--repo").removeprefix("id:"))
            return ok({})
        if verb == ["worktree", "create"]:
            rid = opt("--repo").removeprefix("id:")
            clone = next(p for p, r in self.repos.items() if r == rid)
            branch, name = opt("--branch"), opt("--name")
            assert opt("--base-branch").startswith("origin/") and opt("--setup") == "skip" and "--no-parent" in args
            # Live check: Orca renames a branch with commits of its own. muster never asks it for an existing one.
            assert (clone, branch) not in self.branches, "orca worktree create on an existing branch"
            path = str(Path(orca.ROOT) / Path(clone).name / name)

            return ok({"worktree": {"id": self.wid(path), "path": path, "branch": f"refs/heads/{branch}"}})
        if verb == ["worktree", "rm"]:

            return ok({})
        if verb == ["worktree", "ps"]:
            self.advance_boot()
            rows = {}
            for h, t in self.terminals.items():
                row = rows.setdefault(t["worktreeId"], {"worktreeId": t["worktreeId"], "path": t["worktreePath"],
                                                        "agents": []})
                if h in self.orca_agents:

                    row["agents"].append({"paneKey": self.pane_key(h), "agentType": a["agentType"],
                                          "state": a["state"], "stateStartedAt": a["stateStartedAt"]})
            return ok({"worktrees": list(rows.values()), "truncated": False})
        if verb == ["terminal", "list"]:
            wanted = opt("--worktree").removeprefix("id:") if "--worktree" in args else None
            rows = []
            for h, t in self.terminals.items():
                if wanted and t["worktreeId"] != wanted:
                    continue
                rows.append({"handle": h, "connected": True, "orphaned": t["orphaned"],
                             "recordedPaneKey": t["recordedPaneKey"],

                             **{k: t[k] for k in ("worktreeId", "worktreePath", "tabId", "leafId", "ptyId")}})
                t["late"] -= 1
            return ok({"terminals": rows})
        if verb == ["terminal", "create"]:
            sel = opt("--worktree")

                                    "paneKey": self.pane_key(handle), "tabId": t["tabId"], "ptyId": t["ptyId"]}})
        if verb == ["terminal", "set-pane-title"]:

            if handle not in self.orca_agents:  # a shell: muster types Claude's command line
                assert "--enter" in args and "--wait-submit" not in args

                return ok({"send": {"handle": handle, "accepted": True}})

            stages = ["input_accepted"]

                stages.append("turn_started")
                self.seq += 1
                self.orca_agents[handle].update(state=self.after_turn, stateStartedAt=self.seq)

            return ok({})

        self.orca_agents.pop(handle, None)
        for pid in [p for p, (ppid, _) in self.procs.items() if p in (t["login"], t["shell"]) or ppid == t["shell"]]:
            self.procs.pop(pid, None)
            self.cwds.pop(pid, None)
```

```python
"""orca: muster's runs in Orca: a checkout, a terminal titled with the agent's name, Claude typed into it.

Every shape here was checked live on 2026-11-12 (docs/plans/2026-11-12-orca-host.md, "Live check"). Orca's terminal
handles go stale when Orca restarts, and its rows come back orphaned (no title, no agent, recordedPaneKey = the old
tab:leaf), so muster's pane is its own durable key, "orca:<worktree id>#<title>#<tab id>:<leaf id>", resolved on
every call. An orphaned match is unknown, never gone. Orca's agent detection rides on its wrapper around `claude`
in its shells, so Claude is typed into a shell, never exec'd with `env`.
"""

import json
import shlex
import time
from pathlib import Path

from .. import core
from . import READY, Blocked

NAME = "orca"
ROOT = "~/orca/workspaces"  # Orca's default workspace directory: <ROOT>/<clone dir name>/<worktree name>
# Orca's agent states (live check) -> muster's. Anything else passes through prefixed: never ready, never delivered.
STATE = {"working": "working", "waiting": "blocked", "done": "done", "idle": "idle"}
TITLE_WAIT = 5    # s a new terminal takes to show its pane title (about 1 s observed)
START_WAIT = 120  # s Claude may take to be ready (herdr's start --timeout 120000)
clock, sleep = time.time, time.sleep  # tests replace both


def result(*args):
    return json.loads(core.run(["orca", *args, "--json"]))["result"]


def known_repo(clone):
    """Orca's id for a clone or folder, or None when Orca does not know it (nothing is added)."""
    try:
        return result("repo", "show", "--repo", f"path:{clone}")["repo"]["id"]
    except core.CommandError as error:
        if "repo_not_found" not in str(error):
            raise
    return None


def repo_id(clone):
    """Orca's id for a clone or folder, adding it to Orca the first time."""
    return known_repo(clone) or result("repo", "add", "--path", str(clone))["repo"]["id"]


def worktree_path(clone, branch):
    """Where Orca puts a worktree named after the branch; git's checkout for an existing branch goes there too."""
    return str(Path(ROOT).expanduser() / Path(clone).name / branch.replace("/", "-"))


def worktrees(clone):
    """Every git worktree of the clone, from git: Orca's own list leaves out checkouts it did not create. Read-only:
    a clone Orca does not know yet has no workspace open (open_workspace_id None)."""
    rid = known_repo(clone)
    found, entry = [], None
    for line in core.run(["git", "-C", str(clone), "worktree", "list", "--porcelain"]).splitlines() + [""]:
        if line.startswith("worktree "):
            entry = {"path": line[len("worktree "):], "branch": None}
        elif line.startswith("branch ") and entry:
            entry["branch"] = line[len("branch "):].removeprefix("refs/heads/")
        elif not line and entry:
            found.append(entry)
            entry = None
    for n, wt in enumerate(found):
        wt["is_linked_worktree"] = n > 0  # git lists the main checkout first
        wt["open_workspace_id"] = f"{rid}::{wt['path']}" if rid else None
    return found


def create_worktree(clone, branch, base, path, label):
    """Orca's own create for a new branch. An existing branch gets git's checkout at the same place, since Orca
    renames a branch with commits of its own (muster/3 -> muster/3-2); the repo then shows external worktrees, so
    the checkout is visible in Orca. label: unused (Orca names the worktree by its directory). Setup hooks are
    skipped: builders own dependency setup (#69)."""
    rid = repo_id(clone)
    try:
        core.run(["git", "-C", str(clone), "rev-parse", "--verify", "--quiet", f"refs/heads/{branch}"])
    except core.CommandError:
        made = result("worktree", "create", "--repo", f"id:{rid}", "--name", Path(path).name, "--branch", branch,
                      "--base-branch", f"origin/{base}", "--setup", "skip", "--no-parent")["worktree"]
        return {"workspace": made["id"], "path": made["path"]}
    core.run(["git", "-C", str(clone), "worktree", "add", path, branch])
    result("repo", "set", "--repo", f"id:{rid}", "--external-worktree-visibility", "show")
    return {"workspace": f"{rid}::{path}", "path": path}


def open_worktree(clone, path, label):
    """Orca needs no open: a checkout's workspace is its id."""
    return f"{repo_id(clone)}::{path}"


def key(workspace, title, pane_key):
    return f"orca:{workspace}#{title}#{pane_key}"


def parse(pane):
    """(workspace, title, tab:leaf) of a pane key; the workspace may hold '#', the other two never do."""
    workspace, title, pane_key = pane.removeprefix("orca:").rsplit("#", 2)
    return workspace, title, pane_key


def terminals(workspace=None):
    """Orca's terminal rows, orphaned ones included."""
    rows = result("terminal", "list", *(["--worktree", f"id:{workspace}"] if workspace else []))["terminals"]
    return [t for t in rows if workspace is None or t.get("worktreeId") == workspace]


def agents(workspace):
    """tab:leaf -> Orca's agent row, for the workspace's agents that a window shows."""
    for w in result("worktree", "ps", "--limit", "10000")["worktrees"]:
        if w.get("worktreeId") == workspace:
            return {a["paneKey"]: a for a in w.get("agents") or [] if a.get("paneKey")}
    return {}


def own(row):
    return f"{row['tabId']}:{row['leafId']}"


def find(pane):
    """Orca's terminal row for a pane key (orphaned or not), or None when no terminal matches it."""
    workspace, title, pane_key = parse(pane)
    rows = [t for t in terminals(workspace)
            if own(t) == pane_key or t.get("recordedPaneKey") == pane_key
            or (t.get("paneTitle") == title and not t.get("orphaned"))]
    if len({t["handle"] for t in rows}) > 1:
        raise core.CommandError(f"orca: {len(rows)} terminals in {workspace} match {title}; close the extra one")
    return rows[0] if rows else None


def live(pane):
    """The pane's row when a window shows it. Raises (unknown, try later) when it is orphaned or gone."""
    row = find(pane)
    if row is None:
        raise core.CommandError(f"orca: no terminal for {pane}")
    if row.get("orphaned"):
        raise core.CommandError(f"orca: the terminal for {pane} is detached from Orca's window (Orca restarted?); "
                                f"open its workspace in Orca")
    return row


def pane(pane_id):
    row = find(pane_id)
    return {"pane_id": pane_id, "workspace_id": row["worktreeId"]} if row else None


def panes(workspace):
    showing = agents(workspace)
    return [{"pane_id": key(workspace, t.get("paneTitle") or t["handle"], own(t)), "workspace_id": workspace,
             "terminal_id": t["ptyId"],
             "agent": (showing.get(own(t)) or {}).get("agentType") or ("unknown" if t.get("orphaned") else None)}
            for t in terminals(workspace)]


def open_tab(workspace, path, label, env, title):
    """A shell titled with the agent's name. A titled shell left by a crash after create is reused; env is applied
    when Claude starts (start_agent). path, label: unused (the workspace is the checkout)."""
    for t in terminals(workspace):
        if t.get("paneTitle") == title and not t.get("orphaned"):
            return key(workspace, title, own(t))
    made = result("terminal", "create", "--worktree", f"id:{workspace}", "--title", title)["terminal"]
    pane_id = key(workspace, title, made["paneKey"])
    deadline = clock() + TITLE_WAIT
    while (find(pane_id) or {}).get("paneTitle") != title:
        if clock() >= deadline:
            result("terminal", "set-pane-title", "--terminal", made["handle"], "--title", title)
            break
        sleep(0.5)
    return pane_id


def agent(target):
    """The agent in a pane (a key) or under a name (a pane title anywhere), in herdr's shape; None when there is
    none. Raises when Orca cannot tell (an orphaned terminal)."""
    if target.startswith("orca:"):
        row = find(target)
    else:
        rows = [t for t in terminals() if t.get("paneTitle") == target and not t.get("orphaned")]
        if len(rows) > 1:
            raise core.CommandError(f"orca: {len(rows)} terminals in Orca are titled {target}; close the extra one")
        row = rows[0] if rows else None
    if row is None:
        return None
    if row.get("orphaned"):
        live(target)  # raises: unknown
    found = agents(row["worktreeId"]).get(own(row))
    if not found:
        return None
    state = found.get("state")
    workspace, title = row["worktreeId"], row.get("paneTitle")
    pane_id = target if target.startswith("orca:") else key(workspace, title, own(row))
    return {"agent": found.get("agentType"), "name": title or parse(pane_id)[1], "cwd": row.get("worktreePath"),
            "foreground_cwd": None, "agent_status": STATE.get(state, f"orca-{state}"),
            "state_change_seq": found.get("stateStartedAt"), "completion_seq": None,
            "pane_id": pane_id, "workspace_id": workspace}


def start_agent(name, kind, pane_id, args, env):
    """Type `export <env>; <kind> <args>` into the pane's shell, then wait until Claude is ready or shows a dialog
    (herdr's start contract)."""
    # ponytail: a crash after typing and before the agent shows (up to START_WAIT) leaves recovery typing the line
    # again, into Claude this time; it then reads busy and a person recovers. Check the shell's children first if
    # that ever happens.
    row = live(pane_id)
    line = " ".join(shlex.quote(a) for a in [kind, *args])
    if env:
        line = "export " + " ".join(shlex.quote(pair) for pair in env) + "; " + line
    result("terminal", "send", "--terminal", row["handle"], "--text", line, "--enter")
    deadline = clock() + START_WAIT
    while clock() < deadline:
        now = agent(pane_id)
        if now and now["agent_status"] in (*READY, "blocked"):
            return
        sleep(1)
    raise core.CommandError(f"orca: {kind} was not ready in {pane_id} within {START_WAIT} s")


def prompt(pane_id, text):
    """One prompt with Orca's proof: `turn_started` is delivered (working, or blocked when a dialog is already up);
    agent_prompt_blocked sent nothing; anything else is unproven."""
    row = live(pane_id)
    try:
        sent = result("terminal", "send", "--terminal", row["handle"], "--text", text, "--enter",
                      "--wait-submit", "30")["send"]
    except core.CommandError as error:
        if "agent_prompt_blocked" in str(error):
            raise Blocked(str(error)) from None
        raise
    if "turn_started" not in ((sent.get("prompt") or {}).get("stages") or []):
        raise core.CommandError(f"orca: the prompt to {pane_id} was accepted; no turn start was seen in 30 s")
    now = agent(pane_id)
    return "blocked" if now and now["agent_status"] == "blocked" else "working"


def screen(pane_id):
    row = live(pane_id)
    return "\n".join(result("terminal", "read", "--terminal", row["handle"], "--screen")["terminal"]["tail"])


def remove_argv(workspace, path, force):
    """Orca's rm takes Orca-made and git-made checkouts alike, closes their terminals and keeps the branch."""
    return ["orca", "worktree", "rm", "--worktree", f"path:{path}", *(["--force"] if force else []), "--json"]
```

```python
def cwd_pids(path):
    """pids of processes whose working directory is the checkout or inside it."""
    found, pid = set(), None
    for line in core.run(["lsof", "-a", "-d", "cwd", "-Fpn"]).splitlines():
        if line.startswith("p"):
            pid = int(line[1:])
        elif line.startswith("n") and (line[1:] == path or line[1:].startswith(path + "/")):
            found.add(pid)
    return found


# ponytail: an analysis folder's own terminals (not only muster's) count too, so a folder the human works in stays
# open; scope to muster's terminal if that bites.
def quiet(workspace):
    """Each terminal's evidence. NotReady when one is busy or unknown: an orphaned terminal (Orca shows no agent for
    it), an agent not idle or done, a Claude process Orca shows no agent for, anything under a terminal's shell but
    the agent, a nested shell or an MCP/language server, a process in the checkout outside any terminal's shell, or
    fewer shells in the checkout than Orca has terminals (one left it, so its jobs cannot be seen). Orca shows no
    shell pid per terminal, so shells are found by working directory (lsof)."""
    path = workspace.split("::", 1)[1]
    rows = terminals(workspace)
    if not rows:
        raise NotReady(f"workspace {workspace} lists no terminals")
    showing, seen = agents(workspace), []
    for t in sorted(rows, key=lambda t: t["ptyId"]):
        if t.get("orphaned"):
            raise NotReady(f"terminal {t['ptyId']} is detached from Orca's window; its agent cannot be seen")
        a = showing.get(own(t))
        status = STATE.get(a.get("state"), a.get("state")) if a else None
        if a and status not in READY:
            raise NotReady(f"terminal {t.get('paneTitle') or t['handle']}: {a.get('agentType')} is {status}")
        text = "\n".join(result("terminal", "read", "--terminal", t["handle"], "--screen")["terminal"]["tail"])
        seen.append([t["ptyId"], [a.get("agentType"), a.get("state"), a.get("stateStartedAt")] if a else None,
                     hashlib.sha256(text.encode()).hexdigest()])
    table, inside = processes(), cwd_pids(path)
    roots = sorted(p for p in inside if p in table and table[p][0] not in inside)
    odd = [p for p in roots if program(table[p][1]) not in QUIET]
    if odd:
        raise NotReady(f"{path}: {table[odd[0]][1][:80]} runs outside any terminal's shell")
    if len(roots) < len(rows):
        raise NotReady(f"{path}: {len(rows)} terminals but {len(roots)} shells: a shell left the checkout")
    kind, agents_running = core.adapter().KIND, 0
    for shell in roots:
        tree = under(shell, table)
        for _, depth, command in tree:
            if depth == 1 and program(command) == kind:
                agents_running += 1  # judged by Orca's state above
            elif not (depth == 1 and program(command) in QUIET) and not helper(command):
                raise NotReady(f"{path}: {command[:80]} is running")
        seen.append([shell, [p for p, _, _ in tree]])
    if agents_running > len(showing):
        raise NotReady(f"{path}: {agents_running} {kind} processes but Orca shows no state for "
                       f"{agents_running - len(showing)} of them")
    return seen


def open_workspace(cwd, label):
    """A terminal muster owns in a folder, the folder added to Orca the first time. label: the record's; the pane
    title is unique per open, so two opens of one folder stay apart."""
    title = f"muster-{secrets.token_hex(4)}"
    try:
        made = result("terminal", "create", "--worktree", f"path:{cwd}", "--title", title)["terminal"]
    except core.CommandError as error:
        if "selector_not_found" not in str(error):
            raise
        result("repo", "add", "--path", cwd, "--kind", "folder")
        made = result("terminal", "create", "--worktree", f"path:{cwd}", "--title", title)["terminal"]
    return {"workspace": made["worktreeId"], "terminal": made["handle"],
            "pane": key(made["worktreeId"], title, made["paneKey"])}


def analysis_gone(rec):
    """Its terminal was closed by hand. An orphaned one is not gone. (Orca cannot remove a folder project from its
    CLI; the folder stays listed in Orca.)"""
    return find(rec["pane"]) is None


def analysis_check(rec):
    live_or_not = find(rec["pane"])
    if live_or_not is None:
        raise NotReady(f"terminal {rec['pane']} is gone")


def close_argv(rec):
    """Close muster's own terminal, found again (its handle may be stale), never the folder's other terminals."""
    row = find(rec["pane"])
    if row is None:
        raise NotReady(f"terminal {rec['pane']} is gone")
    return ["orca", "terminal", "close", "--terminal", row["handle"], "--json"]
```
